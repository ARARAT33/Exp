06 · PUBLISHING STANDARD

Open by default.
Clean by design.

We keep the rules intentionally simple. The goal is a useful, safe and open collection — not a complicated gatekeeping system.

Read the full policy ↗
01Open source

Source code must be available and released under an open-source license.

02Minimum 2 files

Every project must contain at least two files. Static websites have a maximum of 10 files and 2 folders.

03No ads or abuse

No advertisements, malicious, illegal, deceptive or abusive content.

04No unauthorized links

Projects must not contain unauthorized, deceptive, malicious or unrelated links.

05Review required

Submission starts a review. It does not guarantee publication, integration or promotion.

09 · FAQ

Questions, answered.

Is every submitted project accepted?

No. Every submission is reviewed, and publication is not guaranteed.

Does every project need to be open source?

Yes. AWEEXP is an open-source project exchange.

What is the static website limit?

A static website must contain at least 2 files and at most 10 files across no more than 2 folders.

Can apps and other project types exceed that limit?

Yes. The 10-file/2-folder limit is specifically for static web projects. Other project types follow the general AWEEXP standards.
