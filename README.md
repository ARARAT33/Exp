# AWEEXP

AWEEXP is the open-source project publishing platform for AWE projects and community projects.

## Project limits

- Static web projects: 2–10 files and up to 2 folders per project.
- Other project types: no project file-count limit; the published page exposes the appropriate build/download artifact.
- Every submitted project must be open source.
- Projects must contain at least 2 files.
- No advertisements, illegal content, malicious content, or unauthorized links.
- Submission does not guarantee acceptance.

See `POLICY.md` for the full publishing rules.
